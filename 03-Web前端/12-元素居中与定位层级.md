# 元素居中与定位层级

## 一，方法1

### 1.必须知道子元素的宽高（示例子元素宽高为 200px）

```css
.app{
     position: absolute;
            top: 50%;
            left: 50%;
            margin-left: -100px;
            margin-top: -100px;
}
```

## 二，方法2

### 1.子元素必须比父元素小

```css
.app{
     position: absolute;
            top: 0px;
            left: 0px;
            bottom: 0px;
            right: 0px;
            margin: auto;
}
```

## 三，改变定位层级

### 1.属性:z-index

### 2.属性值:数值(可以为负数)

### 3.特点

1. 数值越大优先级越高
2. 当z-index值都一样时，标签顺序越靠下优先级越高
3.  z-index默认值0
