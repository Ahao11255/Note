# 📒 笔记库

个人学习笔记，以 [Obsidian](https://obsidian.md/) 仓库（vault）形式维护，覆盖 **Java、C 语言、Web 前端、软件测试、计算机基础** 五个领域。

## 打开方式

用 Obsidian 的「打开文件夹作为仓库」选择本目录即可。仓库已预置好：

| 配置项 | 值 | 作用 |
| --- | --- | --- |
| 附件目录 | `99-附件/` | 新粘贴的图片自动落到这里 |
| 关系图谱配色 | 6 个配色分组 | `Ctrl+G` 打开时按领域着色 |
| 标签面板 | 已开启 | 每篇笔记都带 `tags` |
| 属性面板 | 已开启 | 可直接编辑 YAML frontmatter |

## 三个入口

- **文字版地图**：[[知识图谱总览]] —— 全库 MOC，含结构图、领域索引、跨领域关联、学习路线
- **画布版图谱**：[[知识图谱.canvas]] —— 手工排版的 Canvas 关系图

## 笔记规范

新增或修改笔记时请遵守以下约定，保证图谱不断链：

1. **命名**：Web 前端系列用 `NN-主题名.md`，其他领域用 `主题名.md`。
2. **frontmatter**：每篇必须有 `title` / `tags` / `aliases`；`title` 必须与该文件的 H1 完全一致。
3. **标题层级**：全文只有一个 `#`（一级标题，内容等于 `title`），其余依次 `##`、`###`，**不允许跳级**（如 `##` 直接接 `####`），也不要给标题加缩进。
4. **图片**：统一放 `99-附件/`，用 `![[文件名.png]]` 引用。Obsidian 按文件名（basename）解析，因此移动目录不会断链；不要使用 `![alt](C:\...\x.png)` 这类绝对路径。
5. **跨笔记引用**：用 `[[笔记名]]`，需要显示别名时写 `[[笔记名|显示文字]]`，指向小节时写 `[[笔记名#小节标题]]`。
6. **代码块**：必须标注语言（`java` / `css` / `html` / `c`）。
7. **表格**：使用 GFM 管道表，不要用 `====` 之类的字符拼表格。
8. **相关笔记**：每篇末尾加一节

   ```markdown
   ## 相关笔记

   - [[目标笔记]] —— 一句话说明关联
   ```

   这一节就是 Obsidian 关系图谱里这条边的来源。

## 知识图谱是怎么来的

图谱有三层，互为补充：

| 层级 | 载体 | 特点 |
| --- | --- | --- |
| 文字 | `00-知识图谱/知识图谱总览.md` | 人工整理的结构图、索引、交叉点表、学习路线 |
| 画布 | `00-知识图谱/知识图谱.canvas` | 手工排版的节点与箭头，可拖动编辑 |
| 自动 | Obsidian `Ctrl+G` 关系图谱 | 扫描全库 `[[wikilink]]` 自动生成，领域配色 |

**自动图谱的边 = 每篇笔记末尾的「相关笔记」+ 正文里的 `[[...]]`。** 所以想让新笔记进入图谱，只要在它的「相关笔记」里指向已有笔记（或者被已有笔记指向）即可。

## 遗留项

以下文件不属于笔记内容，保留未删（删除需要确认）：

- `desktop.ini` —— Windows 资源管理器生成的文件夹视图配置
- `JUnit单元测试/.obsidian/` —— 历史遗留的嵌套仓库配置（Obsidian 只读取根目录的 `.obsidian`，因此这个目录不生效，可安全删除）
