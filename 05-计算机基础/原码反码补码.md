# 原码 · 反码 · 补码

## 原码

十进制数据在计算机中的二进制表现形式：最高位是**符号位**（0 表示正，1 表示负），其余位是数值位。

### 原码的弊端

用原码做正数运算完全没有问题；但做负数运算时结果会出错，实际运算方向与正确方向相反。

（例如 `1 + (-1)` 用原码计算会得到 `-2` 而不是 `0`。）

## 反码

为了解决「原码不能正确计算负数」的问题而出现。

### 反码的计算规则

正数的反码与原码相同；**负数的反码 = 原码的符号位不变，数值位按位取反**。

### 反码的弊端

负数运算时，如果结果**不跨 0** 没有问题；一旦结果**跨 0**，就会与实际结果相差 1。

根本原因是 0 在原码与反码中有 `+0` 和 `-0` 两种表示。

## 补码

为了解决「负数运算结果跨 0 时出现偏差」的问题而出现。

### 补码的计算规则

正数的补码与原码相同；**负数的补码 = 反码 + 1**（符号位不变）。

另外，补码还能多表示一个特殊值 `-128`（以 8 位为例），该数据在 8 位下没有对应的原码和反码。

### 补码的注意点

计算机中**存储和计算都是以补码的形式进行**的；算完之后再把补码还原成原码，才是人看到的数值。

## 示例（8 位，以 -5 为例）

| 形式 | 求法                 | 二进制      | 十进制 |
| ---- | -------------------- | ----------- | ------ |
| 原码 | 符号位 1 + 5 的二进制 | `1000 0101` | -5     |
| 反码 | 原码数值位按位取反    | `1111 1010` | -5     |
| 补码 | 反码 + 1             | `1111 1011` | -5     |

## 注意

正数的原码、反码、补码完全相同；只有负数才需要区分三者。
